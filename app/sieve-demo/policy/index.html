Public demo: a real scan of a deliberately vulnerable sample app, read-only. Reviews shown were made by the Sieve maintainers.

Pull request policy

Applied only to vulnerabilities a pull request introduces or makes reachable. The first matching rule decides; a check lists every finding with the rule that matched it. Version 1.

Rules

  1. Blockwhen it is known to be exploited, and reachability is reachableKnown-exploited vulnerability reachable from application code
  2. Blockwhen reachability is reachable, and severity is critical or higherCritical vulnerability reachable from application code
  3. Warnwhen reachability is reachable, and severity is high or higherHigh-severity vulnerability reachable from application code
  4. Warnwhen reachability is needs review, and severity is high or higherHigh-severity vulnerability whose reachability needs review
